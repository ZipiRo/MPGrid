Breadth-First Search

How It Works

Breadth-First Search (BFS) is a pathfinding algorithm that explores nodes level by level.

S . . # # # . # . . . E
1. Start from the starting node.
2. Add the node to a queue.
3. Visit all neighboring nodes.
4. Add unvisited neighbors to the queue.
5. Repeat until the end node is found.
6. Because BFS expands evenly, it always finds the shortest path in an unweighted grid.

Pseudo Code
BFS(grid, start, end)

    CREATE queue
    CREATE visited set

    ADD start TO queue
    MARK start AS visited

    WHILE queue IS NOT empty

        current = REMOVE first element FROM queue

        IF current = end
            RETURN path found

        FOR EACH neighbor OF current

            IF neighbor IS inside grid
            AND neighbor IS NOT a wall
            AND neighbor IS NOT visited

                MARK neighbor AS visited
                ADD neighbor TO queue

    RETURN no path found
