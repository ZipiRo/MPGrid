Prim Maze Generator

How It Works

Prim is a maze generation algorithm that builds a maze by gradually expanding from a starting point. It treats the grid like a graph and always connects the maze by choosing the cheapest (random) edge that expands the frontier.

# # # # # # . # . # # # # # # # . # . # # # # # #

The maze grows outward like a “carving” process, always connecting new cells to the existing maze.

1. Start with a grid full of walls.
2. Pick a random starting cell and mark it as part of the maze.
3. Add all walls adjacent to this cell into a frontier list.
4. Randomly pick a wall from the frontier.
5. If the wall connects a visited cell and an unvisited cell, carve a passage.
6. Add the newly visited cell's walls to the frontier.
7. Repeat until there are no more frontier walls.

Pseudo Code
PrimMaze(grid)

    start = random cell
    mark start as part of maze

    frontier = all walls around start

    WHILE frontier is not empty

        wall = random frontier wall
        remove wall from frontier

        IF wall connects visited cell and unvisited cell

            remove wall (carve path)

            mark new cell as visited

            add neighboring walls of new cell to frontier

    return maze
