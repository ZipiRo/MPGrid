What is MPGrid?

MPGrid is an interactive pathfinding and maze generation visualizer that helps you understand algorithms visually through real-time simulation.

It is built for learning, experimenting, and exploring how algorithms behave on grids.

Pathfinding Maze Generation Visualization

Features

BFS / DFS visualization
Maze generation algorithms
Real-time grid interaction
Modular system design
Themes & customization
FPS & performance stats

How It Works

The grid is made of nodes. Algorithms explore these nodes step-by-step, updating the visual state in real time.

  • Walls block traversal
  • Algorithms expand based on rules
  • Path is reconstructed at the end

Modules

  • Pathfinding: visualize pathfinding algorithms
  • Maze Generator: create procedural mazes
  • Topography: modify terrain behavior

Quick Controls

  • Space: Start simulation
  • P: Pause / Resume
  • R: Reset
  • C: Clear grid
  • Tab: Toggle sidebar
