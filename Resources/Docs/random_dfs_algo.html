Random Depth-First Search

How It Works

Randomized DFS is a variation of Depth-First Search where the algorithm randomly chooses which direction to explore next. This creates unpredictable maze-like paths and is often used in maze generation, but it can also be used as a pathfinding strategy.

S . . # # # . # . . . E
1. Start from the starting cell.
2. Mark the current cell as visited.
3. Get all valid neighbors (up, down, left, right).
4. Shuffle the neighbors randomly.
5. Visit each neighbor recursively in that random order.
6. Stop when the end node is found or all paths are exhausted.

Pseudo Code
RandomDFS(node)

    MARK node AS visited

    IF node = end
        RETURN true

    neighbors = GET all valid neighbors of node
    SHUFFLE neighbors randomly

    FOR EACH neighbor IN neighbors

        IF neighbor is NOT visited

            IF RandomDFS(neighbor) = true
                RETURN true

    RETURN false
