How To Use

MPGrid

MPGrid is an interactive pathfinding and maze generation visualizer where you can create grids, place walls, generate mazes, and watch algorithms solve them step by step.

Controls

Mouse Controls

LMB Place
RMB Remove
Ctrl + Wheel Switch algorithm

Interface Controls

LShift Show module settings
I Show module info
Esc Close windows/popups
Tab Hide sidebar
H Hide interface
A Open algorithm documentation

Algorithm Controls

Space Start algorithm
P Pause / Play algorithm
T Random algorithm positions
F Fill grid
C Clear grid
R Reset algorithm/grid

Modules

1 Topography module
2 Pathfinding module
3 Maze generator module
Interface Overview
The MPGrid interface is divided into five main areas: Menu Bar, Sidebar, Grid, Bottom Bar, Module List, Module Settings Window, Module Info Window and Popup Windows.

Menubar

The top menu contains grouped dropdown menus used for configuration and file actions.

  • Grid: resize, save, load, theme switch
  • Settings: background color, sound volume
  • Help: keybinds and documentation

Sidebar

The sidebar is used to select modules and algorithms, and control execution tools.

  • Pathfinding module
  • Maze generator module
  • Topography module

Grid (Main View)

This is the core workspace where all algorithms run.

  • Place and remove walls
  • Set start and end nodes
  • Watch real-time visualization

Bottombar

Displays real-time performance and simulation data.

  • FPS counter

Module List

Shows the active module, and use to select one of them.

  • Topografy
  • Pathfinding
  • Mazer

Module Info Window

Displays information about the current running algorithm.

  • Elapsed Time
  • Path Length
  • Visited Cells Count
  • Carved/Placed Walls Count

Module Settings Window

Settings for the current active module.

  • Custom Colors

Popup System

All configuration is handled through popup windows instead of separate pages.

  • Grid (resize, save/load, theme)
  • Settings (background color, sound volume)
  • Help (keybinds, documentation)
Topogragy Module

How To Draw

1
Select the Topografy Module using the 1 key or from the Left Module List.
2
Select one of the tools, press B or select Brush, press G or select Bucket, press S or select Rectangle, from the Sidebar.
3
Place the Walls using LMB or remove with RMB.
4
Press C or select Clear from Sidebar to clear the grid or F or select Fill to fill the grid.
Pathfinding

How To Use Pathfinding

1
Draw walls using Topography Module or Generate Mazes using Mazer Module
2
Select the Pathfinding Module using the 2 key or from the Left Module List.
3
Place the Start cell and the End cell using LMB or remove them with RMB.
3
Choose a pathfinding algorithm with Ctrl + Mouse Wheel or select from the Sidebar
4
Press Space or select Start from Sidebar to start the visualization.
5
Press R or select Reset from Sidebar to reset the algorithm.
Maze Generating

How To Use Mazer

1
Select the Mazer Module using the 3 key or from the Left Module List.
2
Use F or select Fill from Sidebar to fill the grid with walls or C or select Clear from Sidebar to clear the whole grid.
3
Place the Start cell using LMB or remove with RMB.
4
Choose a maze generator algorithm with Ctrl + Mouse Wheel or select from the Sidebar
5
Press Space or select Start from Sidebar to start the visualization.
6
Press R or select Reset from Sidebar to reset the algorithm.
