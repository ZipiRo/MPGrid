Depth-First Search

How It Works

Depth-First Search (DFS) explores one path as deeply as possible before backtracking.

S . . # # # . # . . . E
1. Start from the starting node.
2. Move to one neighboring node.
3. Continue going deeper until no more moves are possible.
4. Backtrack to the previous node.
5. Try another path.
6. Repeat until the end node is found.
Complete

Optimal

Pseudo Code
DFS(node)

    MARK node AS visited

    IF node = end
        RETURN true

    FOR EACH neighbor OF node

        IF neighbor IS NOT visited

            IF DFS(neighbor) = true
                RETURN true

    RETURN false
