Recursive Backtracking Maze Generator

How It Works

Recursive Backtracking is a depth-first maze generation algorithm. It builds a maze by carving paths forward until it hits a dead end, then backtracks and tries other directions.

# # # # # # . # . # # # . # # # . # . # # # # # #

The algorithm behaves like a “snake” that keeps digging until it gets stuck, then it goes back and tries a different direction.

1. Start from a random cell.
2. Mark the cell as visited.
3. Randomly shuffle the four directions (up, down, left, right).
4. For each direction, move to a neighboring cell if it is unvisited.
5. Carve a path between current cell and next cell.
6. Recursively repeat from the next cell.
7. If no moves are possible, backtrack automatically.

Pseudo Code
RecursiveBacktracking(cell)

    mark cell as visited

    directions = shuffle(up, down, left, right)

    FOR each direction in directions

        next = neighbor cell

        IF next is inside grid AND not visited

            remove wall between cell and next

            RecursiveBacktracking(next)
