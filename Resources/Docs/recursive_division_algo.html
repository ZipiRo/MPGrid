Recursive Division Maze Generator

How It Works

Recursive Division is a maze generation algorithm that works by repeatedly splitting the grid with walls and adding openings (doors). It creates a structured, “room-like” maze instead of a carving-style maze.

# # # # # # # . # . . # # # # . # # # . . . . # # # # # # #

Instead of carving paths, this algorithm builds walls first and then breaks them down with openings.

1. Start with an empty open grid.
2. Choose whether to divide horizontally or vertically.
3. Draw a wall across the selected direction.
4. Create one or more random gaps (doors) in the wall.
5. Recursively apply the same process to the resulting sub-areas.
6. Stop when the area is too small to divide further.

Pseudo Code
RecursiveDivision(x, y, width, height)

    IF width <= 2 OR height <= 2
        RETURN

    IF width > height
        divide vertically
    ELSE
        divide horizontally

    draw wall

    create random passage in wall

    RecursiveDivision(left area)
    RecursiveDivision(right area)
